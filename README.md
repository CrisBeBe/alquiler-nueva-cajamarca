# Alquiler Nueva Cajamarca

Plataforma web de alquileres de cuartos y casas en Nueva Cajamarca.

## Estructura del Proyecto

- **backend/**: Servidor Node.js + Express + SQLite
- **frontend/**: Cliente React

## Requisitos

- Node.js v18+
- npm o yarn
