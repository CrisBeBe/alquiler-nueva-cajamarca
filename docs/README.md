## 🚀 Resumen del Proyecto

**Alquiler NC** es una solución integral para el mercado de alquileres en Nueva Cajamarca, Perú. Permite a los usuarios publicar anuncios, buscar propiedades con filtros avanzados y contactar directamente con los propietarios.

### Tecnologías Principales
- **Frontend:** React, Vite, Tailwind CSS.
- **Backend:** Node.js, Express, Sequelize.
- **Base de Datos:** PostgreSQL (Hosted en Neon).
- **Servicios Cloud:** Cloudinary (Imágenes), Vercel (Hosting), Gemini AI (Mejora de contenido).
