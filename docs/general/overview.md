# Información General del Proyecto

## Propósito
**Alquiler Nueva Cajamarca** nace de la necesidad de centralizar la oferta de alquileres en la ciudad de Nueva Cajamarca. La plataforma facilita la visibilidad de inmuebles y simplifica la búsqueda para los inquilinos.

## Características Clave
- **Publicación de Anuncios:** Los propietarios pueden subir fotos, descripciones mejoradas por IA y detalles técnicos de sus inmuebles.
- **Búsqueda Avanzada:** Filtros por precio, tipo de inmueble, servicios incluidos y ubicación.
- **Panel de Administración:** Gestión de usuarios, anuncios y configuraciones globales del sistema.
- **Optimización por IA:** Integración con Google Gemini para mejorar automáticamente los títulos y descripciones de los anuncios.
- **Notificaciones por Correo:** Verificación de cuenta y recuperación de contraseña.

## Stack Tecnológico
| Capa | Tecnología |
| :--- | :--- |
| **Frontend** | React 18, Vite, Tailwind CSS, Axios, Context API |
| **Backend** | Node.js, Express, Sequelize ORM |
| **Base de Datos** | PostgreSQL (Neon.tech) |
| **Almacenamiento** | Cloudinary (Imágenes) |
| **IA** | Google Gemini 1.5 Flash |
| **Despliegue** | Vercel (Frontend & Backend unificados) |
| **Pruebas** | Playwright (E2E) |
